# Crafts-Island
三端互通全能一体化个人工具箱 | Web + Windows + Android 全栈实战项目

## 项目简介
🔥 一套代码复用三端、双后端架构全栈实战平台，一站式覆盖学习、自律、笔记、密码安全、健康减脂、资源管理、影音收藏、旅行规划、备忘录、GitHub 项目收藏十大场景。
以云端 MySQL 作为唯一数据源，网页、桌面客户端、安卓 APP 任意一端增删改数据实时同步，告别多款软件切换。
同时本项目完整覆盖 Java + Python 双后端、Vue3 前端、Tauri 桌面、UniApp 移动端、数据库缓存、Linux 服务器部署、数据加密、多端同步等全套全栈开发技能，适合毕业设计、个人练手、求职作品集。

## 技术栈
### 后端双引擎
- Java SpringBoot：核心业务接口、用户鉴权、三端数据同步、权限事务
- Python FastAPI：轻量化工具接口、图表生成、饮食数据分析、Markdown解析

### 前端
- Vue3 + Vite + Element Plus 网页管理端

### 数据库 & 缓存
- MySQL：业务数据持久化，多表关联设计
- Redis：登录会话缓存、临时同步数据、性能优化

### 跨端客户端
- Windows：Tauri，复用前端代码，轻量桌面软件，支持离线缓存
- Android：UniApp，同一套业务页面打包 APK，三端 UI/逻辑统一

### 部署 & 安全
- Linux 云服务器 + Nginx 反向代理，前后端分离部署
- AES 对称加密：账号密码加密存储，无明文泄露

## 十大核心功能模块
### 1. 学习计划管理
- 每日/阶段性任务、截止时间、完成状态、科目标签(EE/CS/思政/化学)
- 日历视图、每日完成率统计
- 联动番茄计时器，任务直接启动专注计时，自动记录对应科目时长

### 2. 番茄专注计时器
- 自定义专注/休息时长、自动循环模式
- 云端存储所有专注记录，周/月专注时长可视化图表
- 绑定学习任务，分类统计各科目学习耗时

### 3. Markdown 笔记工具箱
- 左右分栏实时预览，支持图片、代码块、表格
- 笔记分类归档：课程笔记、博客草稿、旅行文案
- 云端实时保存、三端同步，支持导出 PDF

### 4. 加密密码管理器
- AES 加密存储账号密码，分类：校园平台、软件、网站、竞赛平台
- 一键复制账号密码、自定义备注
- 主密码解锁，全程无明文存储，兼顾安全与多端同步

### 5. 个人学习资源库
- 收纳网课链接、PDF、专业书籍、电机仿真、数电模电、编程资料
- 标签检索、收藏、已读/待读标记
- 定向适配电气、计算机专业自学资料管理

### 6. 健康饮食减脂打卡系统（适配脂肪肝减脂）
- 三餐打卡，记录食物名称、克重、每日体重
- Python 后端生成体重、热量变化 ECharts 趋势图
- 食材分类、忌口记录，长期追踪减脂健康数据

### 7. 影音书籍收藏清单
- 书籍：专业教材、课外书，记录阅读进度、读后感、评分
- 影视/纪录片：标记想看、已看完，分类归档管理

### 8. 旅行规划清单
- 自定义行程：起点、景点、交通、预算、行程天数
- 增删景点、备注住宿车次，移动端随时查看
- 支持导出行程文档，适配旅游路线规划

### 9. 备忘录 & 通用任务清单（新增）
- 轻量化临时备忘、日常琐事待办
- 任务优先级、完成勾选、过期提醒
- 独立于学习计划，单独分类管理，三端实时同步

### 10. GitHub 开源项目收藏夹（新增）
- 发现有趣的 GitHub 项目来不及细看，一键收藏：项目名、链接、简介、标签、语言、星标数
- 状态管理：待看 / 已看 / 学习中，按标签快速检索，不再错过好项目
- 三端同步：手机刷到随手存，电脑上慢慢看

## 三端能力介绍
1. **Web 网页端**
浏览器完整访问，全功能开放，适合批量录入资料、长篇笔记编辑、行程精细规划、数据统计分析。

2. **Windows 桌面客户端（Tauri）**
无需浏览器，开机快速启动；支持本地离线缓存，联网自动同步云端；快速打开番茄钟、查看今日计划、浏览备忘录。

3. **Android APP（UniApp）**
随身轻量化使用，外出饮食打卡、查看旅行路线、碎片化记笔记、随时随地专注学习。

### 同步机制
云端数据库唯一可信源，三端实时双向同步，处理离线缓存、数据冲突逻辑，多设备数据完全一致。

## 整体开发流程
1. 数据库表结构设计（十大模块全表、关联关系）
2. SpringBoot 主服务开发：用户、登录、核心业务接口
3. FastAPI 工具服务开发：图表、MD解析、统计接口
4. Vue3 网页前端完整页面开发与接口联调
5. Tauri 打包 Windows 桌面客户端
6. UniApp 页面适配，打包 Android APK
7. 云服务器部署 Java / Python / MySQL / Redis / Nginx
8. 三端联调，同步、离线、兼容性全量测试
