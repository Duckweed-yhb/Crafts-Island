# 第 01 课：认识数据库、MySQL 与 SQL

> 学习目标：搞清楚「数据库 / MySQL / SQL」到底是什么关系，建立正确的心智模型。
> 本课没有代码，纯概念，但这是后面所有课程的地基。

---

## 一、先搞清楚三个词的关系

新手最容易把这三个词混着说，其实它们是**不同层级**的东西。

用「存东西」来类比：

```
仓库              = 数据库（Database）
仓库管理公司        = 数据库管理系统（DBMS）
具体盖仓库的施工队   = MySQL（一款具体的 DBMS 软件）
你指挥工人的语言     = SQL（标准指令语言）
```

| 名词 | 它是什么 | 通俗理解 |
|------|---------|---------|
| **数据库 Database** | 存放数据的"仓库"本身 | 你建的 `crafts_island` 就是一个数据库 |
| **DBMS（数据库管理系统）** | 管理数据库的软件 | 负责存、取、查数据 |
| **MySQL** | 一款具体的 DBMS 产品 | 就像"微信"是众多聊天软件里的一款 |
| **SQL** | 操作数据库的**语言** | 是"指令"，不是软件 |
| **Navicat / DBeaver** | 图形化操作工具 | 让你点鼠标操作，不用敲命令 |
| **Redis** | 另一种数据库（非关系型） | 数据放内存里，速度极快，当缓存用 |

**记住这一句：**

> MySQL 是软件，SQL 是语言，数据库是你用这个软件 + 这门语言创建出来的数据仓库。

---

## 二、数据库家族的「两大类」

| 类型 | 代表 | 用 SQL 吗 | 特点 |
|------|------|:---------:|------|
| **关系型数据库** | MySQL、PostgreSQL、SQLite | ✅ 用 | 像 Excel 表格，字段固定，稳定可靠 |
| **非关系型（NoSQL）** | MongoDB（文档型） | ❌ 不用 | 数据形式自由，灵活 |
| **键值缓存** | Redis、Memcached | ❌ 不用 | 放内存里，极快，当缓存用 |

你项目里的搭配：

| 项目里用的 | 为什么用 |
|-----------|---------|
| **MySQL** | 存核心业务数据（用户、笔记、打卡……），要永久保存、不丢 |
| **Redis** | 存登录会话、临时数据，要快，丢了也不致命 |

> 典型搭配：**MySQL 当"档案柜"存正式数据，Redis 当"便签贴"加速。**

---

## 三、数据库里的「套娃」结构

```
数据库（Database）  →  里面装很多张 表（Table）
表（Table）         →  一张表就像 Excel，有 行 和 列
  列（字段/Field）  →  比如"用户名""密码"，每列有数据类型
  行（记录/Record） →  一条数据，比如一个用户
```

所以任何数据库操作，第一步永远是：**先建库，再建表**。

---

## 四、三个最容易踩的坑

1. **SQL ≠ MySQL**：SQL 是语言，MySQL 是软件。
2. **MongoDB / Redis 不用 SQL**：别用 `SELECT` 去查它们，它们有自己的命令。
3. **Memcached 严格说是"缓存系统"，不算"数据库"**：数据不落盘，重启就没了。
