# 三端工具箱 · 零基础边做边学课程

> 目标：从零基础到独立完成【Crafts-Island·手艺岛】三端个人小岛
> 方法：每学一个知识点，立刻用它搭建项目里真实的一小块，学完即落地
> 周期：约 3 个月（学习 + 实战一体）

---

## 一、这门课怎么学？

**核心原则：不做「先学完再动手」，而是「边做边学」。**

每节课的结构都是：

1. **讲一个概念**（用大白话，不堆术语）
2. **给一段真实代码**（直接是项目里要用的）
3. **留一个小练习**（你动手做）
4. **做完进入下一课**

遇到报错 → 先自己排查 → 卡住了随时问。

## 四、学习节奏建议

- **每天 1~2 小时**，一课一练，不贪多
- 每学完一课，在对应 Markdown 里打勾标记完成
- 每阶段结束，做一次「阶段小总结」，把知识串起来

> 记住：**看懂 ≠ 会做**。每一课的最后都有练习，动手跑通才算过。
