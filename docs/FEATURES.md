## 0. 文档说明

- **一句话**：Crafts-Island 是一座亲手打造的个人小岛，由**内核（岛基座）**与**岛民（可插拔功能模块）**组成，三端互通，覆盖学习、自律、笔记、安全、健康、美食、生活、规划与休闲。
- **本文回答的问题**：①岛上有哪些功能？②每个功能做什么、依赖什么？③哪些是核心、哪些可后加？④刻意不做哪些事？
- **约定**：⚪ 待确认 / 🟢 已明确 / 🔵 进行中。

## 1. 功能总览

```
内核（岛基座，必备）
├── 身份与权限      注册 / 登录 / JWT / 会话 / 插件可见性
├── 三端同步        统一同步协议 / 离线缓存 / 冲突处理
├── 插件装载        插件注册表 / 动态路由 / 动态菜单
└── 统一契约        接口返回格式 {code,msg,data} / 错误码

岛民（可插拔功能，共 15 座 · 全部可选装载）
├── 📚 学习计划        ├── 🍅 番茄专注计时
├── 📝 Markdown 笔记   ├── 🔐 加密密码管理
├── 📦 学习资源库      ├── 🥗 健康减脂打卡
├── 🎬 影音书籍收藏    ├── ✈️ 旅行规划
├── 📌 备忘录任务      ├── ⭐ GitHub 收藏夹
├── ⏱️ 屏幕使用时长    ├── 🧘 修仙养成
├── 🎣 钓鱼小游戏      └── 🐾 电子宠物
└── 🍜 美食宝藏馆

> **插件可选**：内核（岛基座）必备；15 座岛民均可按需装载 —— 启用 / 停用 / 卸载，不必全部使用，按个人需要决定装几座。

横切能力：🔒 AES 加密 · 🖧 三端同步 · 🚀 Linux+Nginx 部署

候选扩展（后期可选）：🔗 笔记链接分享
```

## 2. 内核能力（岛基座）

> 内核只做三件事：**身份权限、三端同步、插件装载**。它们是所有岛民共同依赖的地基，不归属任何单一功能。

### 2.1 身份与权限
| 能力 | 说明 | 状态 |
|------|------|:---:|
| 注册 / 登录 | 用户名 + 密码，AES 加密存储 | ⚪ |
| 会话 | JWT 无状态鉴权 + Redis 会话缓存 | ⚪ |
| 权限体系 | 角色 + 插件可见性控制 | ⚪ |

### 2.2 三端同步
| 能力 | 说明 | 状态 |
|------|------|:---:|
| 唯一数据源 | 云端 MySQL 唯一可信源 | ⚪ |
| 离线缓存 | 桌面/移动端本地缓存，联网自动同步 | ⚪ |
| 冲突处理 | 以 update_time / 最后写入者胜，预留冲突标记 | ⚪ |
| 统一同步接口 | 内核提供增量 pull / push，岛民不各自实现 | ⚪ |

### 2.3 插件装载
| 能力 | 说明 | 状态 |
|------|------|:---:|
| 插件注册表 | 记录岛民、版本、启用状态 | ⚪ |
| 动态路由/菜单 | 按注册表与权限动态生成 | ⚪ |

### 2.4 统一契约
- 所有接口返回 `{ "code": 0, "msg": "ok", "data": {...} }`。
- 全局异常统一处理；错误码集中定义（预留错误码表）。

## 3. 岛民清单（十五大模块）

> 每座岛民统一用四个维度描述：**做什么 / 主要数据 / 依赖 / 三端侧重**。
> 数据 = 该模块的独立数据表（表名带前缀，见架构文档第 5 节）。

### 3.1 📚 学习计划管理
- **做什么**：每日/阶段性任务、截止时间、完成状态；科目标签（EE / CS / 思政 / 化学）；日历视图、每日完成率统计；联动番茄计时器，任务直接启动专注并记录科目时长。
- **主要数据**：`study_task`（任务）、`study_record`（专注记录关联）
- **依赖**：内核；番茄计时器
- **三端侧重**：Web 精细规划 · 桌面快速查看今日 · 移动随时打卡
- **状态**：⚪

### 3.2 🍅 番茄专注计时器
- **做什么**：自定义专注/休息时长、自动循环；云端存储专注记录，周/月专注时长可视化；绑定学习任务，分类统计各科目学习耗时。
- **主要数据**：`study_pomodoro`（专注记录）
- **依赖**：内核；学习计划（可选绑定）
- **三端侧重**：桌面常驻计时 · 移动外出专注
- **状态**：⚪

### 3.3 📝 Markdown 笔记工具箱
- **做什么**：左右分栏实时预览，支持图片、代码块、表格；分类归档（课程笔记 / 博客草稿 / 旅行文案）；云端实时保存、三端同步；导出 PDF。
- **主要数据**：`note_doc`（笔记）、`note_folder`（分类）
- **依赖**：内核；FastAPI（PDF 导出 / MD 解析）
- **三端侧重**：Web 长篇编辑 · 移动碎片记录
- **状态**：⚪

### 3.4 🔐 加密密码管理器
- **做什么**：AES 加密存储账号密码，分类（校园平台 / 软件 / 网站 / 竞赛平台）；一键复制账号密码、自定义备注；主密码解锁，全程无明文存储。
- **主要数据**：`pwd_entry`（密码条目）
- **依赖**：内核 + AES 加密工具
- **三端侧重**：桌面/移动便捷取用
- **状态**：⚪

### 3.5 📦 个人学习资源库
- **做什么**：收纳网课链接、PDF、专业书籍、电机仿真、数电模电、编程资料；标签检索、收藏、已读/待读标记；定向适配电气、计算机专业自学资料。
- **主要数据**：`repo_resource`（资源）、`repo_tag`（标签）
- **依赖**：内核
- **三端侧重**：Web 批量录入 · 移动随手收藏
- **状态**：⚪

### 3.6 🥗 健康饮食减脂打卡（适配脂肪肝减脂）
- **做什么**：三餐打卡，记录食物名称、克重、每日体重；Python 后端生成体重、热量 ECharts 趋势图；食材分类、忌口记录，长期追踪减脂健康数据。
- **主要数据**：`health_meal`（餐次）、`health_weight`（体重）、`health_ingredient`（食材/忌口）
- **依赖**：内核；FastAPI（图表数据）
- **三端侧重**：移动外出打卡 · Web 查看趋势
- **状态**：⚪

### 3.7 🎬 影音书籍收藏清单
- **做什么**：书籍（专业教材、课外书）记录阅读进度、读后感、评分；影视/纪录片标记想看/已看，分类归档管理。
- **主要数据**：`media_book`（书籍）、`media_movie`（影视）
- **依赖**：内核
- **三端侧重**：移动随手标记 · Web 整理归档
- **状态**：⚪

### 3.8 ✈️ 旅行规划清单
- **做什么**：自定义行程（起点、景点、交通、预算、行程天数）；增删景点、备注住宿车次；移动端随时查看；支持导出行程文档。
- **主要数据**：`trip_plan`（行程）、`trip_stop`（景点）
- **依赖**：内核
- **三端侧重**：移动途中查看 · Web 精细规划
- **状态**：⚪

### 3.9 📌 备忘录 & 通用任务清单
- **做什么**：轻量临时备忘、日常琐事待办；任务优先级、完成勾选、过期提醒；独立于学习计划，单独分类管理，三端实时同步。
- **主要数据**：`todo_item`（备忘/任务）
- **依赖**：内核
- **三端侧重**：移动随手记 · 桌面看板
- **状态**：⚪

### 3.10 ⭐ GitHub 开源项目收藏夹
- **做什么**：一键收藏 GitHub 项目（项目名、链接、简介、标签、语言、星标数）；状态管理（待看 / 已看 / 学习中）；按标签快速检索。
- **主要数据**：`github_project`（收藏条目）
- **依赖**：内核
- **三端侧重**：移动刷到随手存 · Web 慢慢看
- **状态**：🟢（表已落地，功能未开发）

### 3.11 ⏱️ 屏幕使用时长监控
- **做什么**：记录手机 / 电脑每日使用时长；按应用与类别统计（学习 / 社交 / 娱乐 / 工具）；设定每日限额与超时提醒；周 / 月使用趋势可视化；可与番茄专注对比，识别"计划专注 vs 实际使用"差距。
- **主要数据**：`screen_record`（使用记录）、`screen_limit`（每日限额）
- **依赖**：内核；番茄专注（可选对比）
- **三端侧重**：桌面常驻统计前台窗口 · 移动通过系统使用情况统计
- **技术要点**：Windows 记录前台活动窗口 / 进程；Android 使用系统「使用情况访问」权限（UsageStats）采集，需用户授权；离线采集、联网同步；**只统计时长与类别，不采集具体输入内容**。
- **状态**：⚪

### 3.12 🧘 修仙养成（自律游戏化 · 休闲向）
- **做什么**：把现实行为映射为"修为"——完成学习任务、番茄专注、减脂打卡即涨修为；境界体系（炼气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 渡劫，每阶多层）；灵根属性绑定学习方向（如电气=火灵根）；功法 / 天赋随修为解锁；境界进度、修炼日志、突破动画。
- **主要数据**：`cult_profile`（角色：灵根 / 境界 / 修为）、`cult_level`（境界与奖励配置）、`cult_log`（修为变动流水）、`cult_bind`（现实行为 ↔ 修为奖励映射）
- **依赖**：内核；学习计划 / 番茄专注 / 减脂打卡（作为修为来源，可选接入）
- **三端侧重**：移动碎片打卡涨修为 · Web 看境界与图鉴
- **技术要点**：纯规则引擎（境界表配置），无复杂游戏逻辑；修为流水可回溯、可导出；不动现实业务数据，只在读取时换算修为。
- **状态**：⚪

### 3.13 🎣 钓鱼小游戏（休闲岛民）
- **做什么**：时机钓鱼（结合番茄休息 / 每日空闲窗口）、鱼获图鉴（稀有度）、背包、装备、账号三端同步；作为"岛民 = 插件"的最佳趣味 demo，验证插件生态与账号同步。
- **主要数据**：`fish_species`（鱼种图鉴）、`fish_catch`（渔获记录）、`fish_bag`（背包 / 装备）
- **依赖**：内核；番茄专注（可选：专注完成后进入"钓鱼休息"）
- **三端侧重**：移动随手钓 · Web 看图鉴
- **技术要点**：轻量前端小游戏 + 数据持久化，无实时对战；稀有度概率配置化；来源：功能思路参考 workday-island（MIT），非搬代码。
- **状态**：⚪

### 3.14 🐾 电子宠物（陪伴养成 · 休闲向）
- **做什么**：通过完成现实行为（学习任务、番茄专注、减脂打卡）赚取喂养道具 / 经验；喂食、互动、升级、进化；饱食度 / 心情 / 亲密度随真实时间自然变化，形成日常陪伴与轻提醒。
- **主要数据**：`pet_profile`（角色：品种 / 等级 / 经验 / 饱食度 / 心情 / 亲密度）、`pet_breed`（品种图鉴与进化规则）、`pet_log`（互动流水）
- **依赖**：内核；学习计划 / 番茄专注 / 减脂打卡（作为喂养来源，可选接入）
- **三端侧重**：移动碎片互动 · Web 看宠物面板
- **技术要点**：状态依赖真实时间衰减——只存 `last_update_time`，读取时按时间差推算当前状态，**无需常驻后台任务**；与修仙同属激励层但定位不同（修仙偏境界成长叙事，宠物偏日常陪伴）。
- **状态**：⚪

### 3.15 🍜 美食宝藏馆（宝藏饭馆收藏 · 探店向）
- **做什么**：收藏宝藏馆子（店名、菜系、地址、招牌菜、人均、评分、标签、照片）；打卡状态管理（想去 / 已去 / 常去），吃过随手更新评分与点评；标签检索（夜宵 / 聚餐 / 宝藏小店）；轻量结合减脂——标注"是否适合减脂期吃"，与健康减脂打卡呼应。
- **主要数据**：`food_restaurant`（馆子收藏）
- **依赖**：内核；健康减脂（可选：is_fit_diet 标注联动）
- **三端侧重**：移动路上随手存 · Web 慢慢整理归档
- **技术要点**：结构与 GitHub 收藏夹同构（收藏 + 状态 + 标签），可复用其开发经验；`image_url` 预留照片展示。
- **状态**：🟢（表已落地，功能未开发）

### 3.16 Agent 工具适配性标注
> 每个岛民都可作为 agent（AI 管家）的一个工具，但**适配度与场景价值不同**。此标注用于排定"AI 管家层"（见架构文档第 5 节）的接入优先级。

| 模块 | 适合的 agent 场景 | 适配度 | 说明 |
|------|------------------|:---:|------|
| 📚 学习计划 | 帮我排本周计划 / 复盘完成率 | ★★★ | 数据结构化，适合排期与复盘 |
| 🍅 番茄专注 | 总结本月专注表现 / 科目耗时分析 | ★★★ | 统计类，LLM 易加工成洞察 |
| 📝 Markdown 笔记 | 笔记问答 / 整理归纳 / 自动分类 | ★★★ | 文本类，天然适合 RAG / 问答 |
| 🥗 健康减脂 | 今晚怎么吃 / 体重趋势解读 / 忌口提醒 | ★★★ | 决策价值最高，可结合忌口给建议 |
| 📦 学习资源库 | 从资料里挑适合入门 X 的 | ★★☆ | 筛选推荐 |
| ⭐ GitHub 收藏 | 挑个前端项目学 / 按标签推荐 | ★★☆ | 筛选推荐 |
| ✈️ 旅行规划 | 生成行程草案 | ★★☆ | 可辅助生成 |
| 📌 备忘录任务 | 合并/排序今日待办 | ★★☆ | 轻量整理 |
| 🎬 影音收藏 | 推荐今晚看什么 | ★☆☆ | 可做但价值一般 |
| ⏱️ 屏幕使用时长 | 总结今日屏幕使用 / 超时提醒 / 与计划对比 | ★★☆ | 统计 + 提醒类，易加工成自律建议 |
| 🧘 修仙养成 | 离下一境界还差多少 / 本周修炼计划 | ★★☆ | 把自律数据转成成长叙事，激励向 |
| 🎣 钓鱼小游戏 | 今日摸鱼报告（娱乐向） | ★☆☆ | 纯休闲，价值一般 |
| 🐾 电子宠物 | 今天宠物状态 / 要不要喂一下 | ★☆☆ | 陪伴向，轻提醒 |
| 🍜 美食宝藏馆 | 附近有没有适合减脂的馆子 / 汇总本月探店 | ★★☆ | 结合位置与 is_fit_diet 可给实用推荐 |
| 🔐 密码管理 | 一般不接入 | ✩ | 敏感数据默认不送 LLM，仅可读建议时脱敏 |

## 4. 功能分级

> 分级用于排定开发顺序，是**建议**，需你确认。

| 级别 | 含义 | 建议归入的功能 |
|------|------|--------------|
| **P0 · 地基** | 先有内核，才有岛 | 用户/鉴权、三端同步、统一契约、插件装载 |
| **P1 · 核心岛民** | 学习场景高频刚需 | 学习计划、番茄专注、屏幕使用时长、Markdown 笔记、备忘录、学习资源库 |
| **P2 · 生活增强** | 个人生活向 | 健康减脂、影音收藏、旅行规划、密码管理、GitHub 收藏、美食宝藏馆 |
| **P3 · 休闲扩展** | 趣味与激励 | 修仙养成、钓鱼小游戏、电子宠物 |

## 5. 边界与取舍

> 防止"手艺岛"膨胀成又一个"全能工具箱"。刻意不做 / 暂不做的事：

| 取舍 | 原因 |
|------|------|
| 不做消息/社交 | 个人项目，聚焦学习与生活，避免做重 |
| 不做复杂富文本协同编辑 | 单人使用，实时保存 + 三端同步已够 |
| 不引入重型搜索 | 用标签 + 简单检索即可 |
| 不做多用户开放平台 | 面向自己，权限到"用户级"即可 |
| 同步冲突策略先做简单 | 最后写入者胜起步，复杂冲突后期再补 |

> 以上为建议，可在第 6 节待决策中调整。
